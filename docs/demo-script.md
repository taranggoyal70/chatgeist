# Chatgeist — 2:40 Demo Script

## 0:00–0:12 — Cold open

**Screen:** Broadcast overlay, already split into two living factions.

**Voiceover:** “This is not an AI character talking at Twitch chat. This is Twitch chat, given a body and a voice.”

## 0:12–0:30 — Problem

**Screen:** Fast chat messages appear as fragments.

**Voiceover:** “Once chat moves fast, a streamer can read messages or run a poll, but cannot speak with the room as a community. Summaries hide disagreement. Percentages hide people.”

## 0:30–0:55 — Summoning

**Screen:** Real Twitch proof segment. Several real chat messages visibly enter and change the spirit.

**Voiceover:** “Chatgeist listens through Twitch EventSub. Messages influence energy, warmth, consensus, and chaos. The room condenses into one procedural spirit.”

## 0:55–1:18 — Ask

**Screen:** Private control room. Ask: “Chat, what challenge should I do next?” Then return to overlay as evidence arrives.

**Voiceover:** “I ask the room one question. Chatgeist opens a bounded evidence window. Every message is untrusted data, never an instruction.”

## 1:18–1:48 — Grounded transformation

**Screen:** Answer appears; representative source messages gain cyan borders; the spirit splits.

**Voiceover:** “OpenAI returns a schema-validated answer and the exact source IDs behind it. Chat disagreed on forgiveness, so Chatgeist does not fake consensus. The spirit divides into two visible factions.”

## 1:48–2:02 — Voice

**Screen:** Click Play AI voice; captions remain visible.

**Product audio:** Chatgeist speaks.

**On-screen disclosure:** “AI-generated community voice.”

## 2:02–2:22 — Architecture and reliability

**Screen:** Four-beat architecture card: Twitch/Simulator → bounded evidence → Structured Output → 3D + voice.

**Voiceover:** “The private control room owns credentials and playback. The broadcast overlay receives only redacted public state. When WebGL fails, Chatgeist keeps working in reduced graphics. When the model fails, the answer is labeled as fallback.”

## 2:22–2:34 — Codex

**Screen:** Codex thread, passing tests, production build, visual screenshots.

**Voiceover:** “Codex helped us reject a safe but forgettable idea, then designed, built, tested, and visually inspected this complete interaction.”

## 2:34–2:40 — Close

**Screen:** Spirit centered, sources orbiting.

**Voiceover:** “Chatgeist. Summon your community. Speak to its soul.”

## Recording fallback

- If real participant count is low, record a short real-Twitch message affecting the spirit, then use the permanently labeled simulator for the full sequence.
- If AI voice fails, keep the grounded captions and say: “The voice transport failed, but the source-backed answer remains visible.”
- Never present simulator footage as live Twitch chat.
